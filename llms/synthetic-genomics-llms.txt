# Viridos (formerly Synthetic Genomics, Inc.)

> Viridos was a La Jolla, California synthetic-biology company applying genome engineering to
> microalgae for low-carbon-intensity biofuels. It is no longer operating: it filed Chapter 11 in
> the District of Delaware on 2025-04-14, sold substantially all of its algae biofuel technology to
> Breakthrough Energy Ventures II, L.P., and the case was dismissed on 2025-11-26. This file is
> generated by API Evangelist from public evidence, not published by the company.

## Status

- Operating status: defunct. Assets sold; no successor developer surface has been published.
- Website: viridos.com resolves but serves nothing. Every path returns a 21-byte
  "403 | Access blocked" page from a SiteGround default vhost, behind a TLS certificate issued for
  giowm1252.siteground.biz that does not cover the domain. The last substantive archived snapshot
  is 2025-09-11; by 2025-10-22 the page had collapsed to roughly 1.4 KB.
- DNS and corporate mail for viridos.com are still live and enterprise-configured (Mimecast
  inbound, Microsoft 365 sending, SPF -all, DMARC p=reject), which outlasted the website.
- Legacy domain warning: syntheticgenomics.com returns HTTP 200 but is NOT the company. The domain
  was dropped and is now a Canadian online-casino affiliate site on Cloudflare. Do not treat it as
  a Viridos source, and do not cite anything published there to this company.

- api., developer., docs., app. and dspace. subdomains of viridos.com do not resolve.

## Open source (the only public developer surface)

- GitHub organization: https://github.com/syntheticgenomics - display name "Viridos Inc.",
  La Jolla California, 9 public repositories, created 2013-01-16.
- https://github.com/syntheticgenomics/sgidspace - Synthetic Genomics D-SPACE Public Library.
  Python, AGPL-3.0, version 1.0.0, last commit 2018-06-27. Deep-learning protein function
  annotation and embedding search trained on UniProt Sprot/TrEMBL and UniRef100. Not on PyPI;
  install from a clone with `pip install -e .`. Its README points at a public demo at
  https://dspace.bio/, which now returns 403 on every path from CloudFront.
- https://github.com/syntheticgenomics/snap-probe-calibrate - TypeScript, last push 2025-03-19.
  Stand-alone calibration app for the modbus L-com SRWQ100-pH104 sensor. No license, no release,
  not on npm.
- The organization's remaining seven repositories are forks of third-party projects (oauthlib,
  requests-oauthlib, oauth2client, uwsgitop, whisper-backup, docker-collectd-plugin,
  docker-python-app), last touched 2017-2018.

## Company background

- Founded 2005 as Synthetic Genomics, Inc. by J. Craig Venter and Hamilton Smith.
- Renamed Viridos on 2021-09-27.
- Algal biofuel research ran as a multi-year partnership with ExxonMobil.
- SGI-DNA, the DNA synthesis instrument business, was separated earlier and is a different company;
  do not attribute its products or APIs to this profile.
